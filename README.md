# Andika Pratama Zaid — Personal Website

Personal branding and portfolio website of **Andika Pratama Zaid**,
Business Development Specialist focused on new ventures, partnerships,
and agribusiness.

Live site: https://andikapratamazaid.github.io

## About

Andika works at the intersection of business development and execution.
He is currently a Business Development Specialist and Assistant to the
Director at PT Modern Jaya Konstruksi (EPC), and previously served as
Secretary to the Board of Directors at PT Eksis Energi Indonesia
(nickel mining). Since 2018 he has founded and run his own ventures,
including Dipo Group and the NGO Indonesia Millennial Connect, and he
currently builds an AI video venture (PT Nusa Inteligensi Media), a
construction company (PT Zeed Enjiniring Construction), and the
ZaidForce AI agent platform.

## Technical notes

- A single self-contained `index.html` file (220 KB): no framework,
  no build step, and no external assets besides Google Fonts. Book
  covers are embedded directly in the file.
- Hosted on GitHub Pages from this repository
  (`andikapratamazaid.github.io`), so the site is served from the
  root domain.
- To update the site, edit `index.html` and commit. To add a project,
  copy an existing project card block and change its title,
  description, and link.
